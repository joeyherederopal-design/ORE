# ᚠ ORE 2.0 — Mobile PWA Deployment Guide

## How to deploy on GitHub Pages:

### Step 1 — Create a GitHub repository
1. Go to **github.com** → click **"+"** → **New repository**
2. Name it: **`ore`** (or any name)
3. Set to **Public**
4. Click **Create repository**

### Step 2 — Upload the 4 files
Upload these files to the repository:
- `index.html`
- `app.js`
- `manifest.json`
- `sw.js`

(Click "Add file" → "Upload files" → drag all 4 files → "Commit changes")

### Step 3 — Enable GitHub Pages
1. In your repo, click **Settings**
2. Left menu → **Pages**
3. Source: **Deploy from a branch**
4. Branch: **main** → folder: **/ (root)**
5. Click **Save**

### Step 4 — Get your URL
Wait 1-2 minutes. GitHub gives you a URL like:
```
https://yourusername.github.io/ore/
```

### Step 5 — Install on your phone
1. Open that URL **on your phone's browser** (Chrome/Safari)
2. ORE loads!
3. **Install as app:**
   - **Android (Chrome):** tap menu (⋮) → "Add to Home screen"
   - **iPhone (Safari):** tap Share (□↑) → "Add to Home Screen"
4. ORE icon appears on your home screen!
5. Tap it → opens like a real app, no browser bar!
